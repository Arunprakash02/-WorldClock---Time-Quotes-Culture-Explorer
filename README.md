# 🌍 Country Time App

An Android application that displays current time, quotes, and images for different countries around the world. Built with Kotlin and Material Design.

## ✨ Features

- 🌐 **Country Selection** - Choose from 22 countries worldwide
- 🕐 **Real-time Clock** - Displays current time for selected country
- 💭 **Random Quotes** - Shows inspiring quotes specific to each country
- 🖼️ **Country Images** - Beautiful Unsplash images for each country
- ❤️ **User Input** - Users can share why they love the country
- 🎨 **Modern UI** - Material Design with responsive layout
- 📱 **Offline Support** - Works without internet (except images)

## 🚀 Technologies Used

- **Language**: Kotlin
- **Architecture**: MVVM (Model-View-ViewModel)
- **UI Framework**: Material Design Components
- **Image Loading**: Glide
- **Time Zones**: Java TimeZone API
- **Minimum SDK**: API 24 (Android 7.0)

## 📋 Prerequisites

- Android Studio Arctic Fox or later
- Android SDK 24 or higher
- JDK 11 or higher
- Internet connection (for loading images)
